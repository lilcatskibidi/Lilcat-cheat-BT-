📚 Hướng dẫn v18.3

Mọi thứ bạn cần biết — giải thích đơn giản

🎯 Xử lý Shuffle tự động

🤔 Vấn đề

Nhiều trang quiz có tính năng shuffle (xáo trộn) đáp án — mỗi lần load lại, thứ tự A/B/C/D sẽ đổi. Parser đọc data gốc trong HTML sẽ hiển thị sai vị trí đáp án so với những gì bạn thấy trên màn hình.

✅ Giải pháp — Chỉ cần dán link

Tool tự động phát hiện shuffle trong HTML, tự động map lại đáp án theo TEXT thay vì letter. Nếu cần, tool còn tự load iframe để đọc DOM thật — chính xác tuyệt đối!

1
Vào tab Cheat → dán link vào ô đầu trang
2
Bấm "🚀 Phân tích" — tool tự fetch HTML
3
Tool tự phát hiện shuffle → nếu cần, tự bật iframe live để đọc DOM
✓
Đáp án hiển thị theo TEXT — chính xác kể cả khi shuffle

1

🧮 Minigame Sinh tồn

Chế độ sinh tồn — không chọn độ khó, tự động tăng cấp khi bạn trả lời đúng!

1
Bắt đầu với Cấp 1 — câu hỏi dễ. Trả lời đúng → lên cấp.
2
Mỗi cấp câu hỏi khó hơn, thời gian ít hơn. Sai 1 câu là kết thúc!
3
Rời tab trong lúc chơi → mất lượt ngay (chống cheat).
4
Streak càng cao, điểm càng lớn. Phá kỷ lục của chính mình!
📊 Cách tính điểm
Điểm = (Cấp × 100) + Streak bonus + Thời gian còn lại × 5. Càng lên cao càng nhiều điểm!

🐱 4 cách đưa bài quiz vào web

1
Chọn file — giống mở file Word trên máy tính. Bạn có sẵn file bài quiz trên máy thì dùng cách này.
2
Dán link — copy đường link của trang bài quiz rồi dán vào ô trống. Khuyến nghị cách này.
3
Dán HTML — nhấn Ctrl+U trên trang quiz, chọn hết (Ctrl+A), copy (Ctrl+C) rồi dán vào ô to.
4
Nhiều link — dán danh sách link vào panel "📚 PHÂN TÍCH NHIỀU LINK", tool xử lý cùng lúc.

❓ Câu hỏi thường gặp

🤔 Quiz shuffle — tại sao đáp án sai?
Vì parser đọc data gốc trong HTML, nhưng quiz đã xáo trộn A/B/C/D khi load. Tool v18.3 đã tự xử lý — chỉ cần dán link, đáp án sẽ hiển thị theo TEXT chính xác.
🤔 Không tìm thấy đáp án?
Có thể trang đó chặn web khác đọc nội dung. Cách chữa: Nhấn Ctrl+U để xem mã nguồn trang, chọn hết Ctrl+A, copy Ctrl+C, rồi dán vào tab "HTML".
🔒 Lỗi CORS là gì?
Giống như nhà hàng không cho người lạ vào bếp. Một số trang web không cho web khác đọc nội dung. Cách chữa: tải file về máy rồi dùng tab "File", hoặc copy HTML dán vào tab "HTML".
🎮 Minigame có lưu điểm không?
Có! Điểm cao nhất, streak và cấp cao nhất được lưu trong trình duyệt của bạn. Xóa dữ liệu trình duyệt sẽ reset.
💾 Web có lưu dữ liệu của tôi không?
Không. Mọi thứ chạy ngay trong trình duyệt của bạn. Web không gửi bài quiz của bạn lên máy chủ nào. Bạn có thể tắt mạng vẫn dùng được (trừ nhạc).
