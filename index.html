🎯 Cách dùng với LMS360

1
Vào tab Cheat → click nút "🚀 Mở LMS360 Hack"
2
Dán link LMS360 của bạn vào ô "Link LMS360" trên trang LMS360 Hack
3
Bấm "Lấy đáp án" — đáp án hiện ra sau vài giây

🐱 Cách dùng Cheat (file/link/HTML)

1
Chọn nguồn — file HTML, dán link web quiz, hoặc dán HTML trực tiếp.
2
Bấm "Kiểm tra" — tool tự tìm biến chứa câu hỏi.
3
Xem đáp án — chuyển tab Đề 1/2/3, bấm Copy để lấy toàn bộ.

📋 3 format được hỗ trợ

Format A — quizData 2D
const quizData = [
  [ {type:'mcq', question, options, answer}, ... ],
  [ ... ]
];
Format B — deckName
const quizData = [
  { deckName: 'Đề 1', questions: [ ... ] },
  { deckName: 'Đề 2', questions: [ ... ] }
];
Format C — de1/de2/de3
const allQuestions = {
  de1: [ { type:'mc', answer:'A' }, ... ],
  de2: [ ... ],
  de3: [ ... ]
};

🎵 Cách dùng nhạc nền

1
Click nút ⚙️ trên widget nhạc (góc dưới trái) để mở cài đặt
2
Chọn bài trong playlist hoặc dán link YouTube/SoundCloud/MP3 vào ô custom
3
Click ▶ trên widget để bật/tắt nhạc, kéo slider để chỉnh âm lượng

❓ FAQ

Không tìm thấy đáp án?
→ Thử copy toàn bộ source (Ctrl+U → Ctrl+A → Ctrl+C) → dán vào tab HTML.
Lỗi CORS?
→ Trang chặn fetch. Dùng tab File hoặc HTML thay thế.
Nhạc không phát?
→ Video YouTube có thể chặn embed. Thử SoundCloud hoặc MP3.
Chia sẻ file thế nào?
→ Đăng nhập → tab Chia sẻ → upload. File lưu cục bộ (IndexedDB).
